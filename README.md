# IRONTRACK — GitHub Pages Edition

## Deploy
1. Upload all files to the root of your GitHub repository.
2. GitHub → Settings → Pages.
3. Select **Deploy from a branch**.
4. Choose `main` and `/ (root)`.
5. Open the published Pages URL and use the browser menu to install IRONTRACK.

## App icon
The project includes SVG, favicon, Apple touch icon, Android/PWA sizes, and maskable PWA icons.

## Data
Workout data is stored locally in the browser. Use IRONTRACK Export JSON for backups and device transfers.
